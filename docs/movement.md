# Movement

- **Grid**: Hex grid. Units face one of the hex's six edges.
- **Costs**: Moving into an adjacent hex costs 1 movement point. Turning 60° costs 1 movement point. Both draw from the same pool. (Per-unit movement point totals are listed with each unit's stats, e.g. `docs/units.md`.)
- **Turning timing**: Turning can happen at the start of a move, the end, or both.
