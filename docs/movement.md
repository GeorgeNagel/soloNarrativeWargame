# Movement

- **Grid**: Hex grid. Units face one of the hex's six edges.
- **Pikemen movement**: 3 movement points per round.
- **Costs**: Moving into an adjacent hex costs 1 movement point. Turning 60° costs 1 movement point. Both draw from the same pool.
- **Turning timing**: Turning can happen at the start of a move, the end, or both.
